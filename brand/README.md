# Spannr brand files

The Spannr symbol is an "S" built from the angles of a hex nut, drawn in amber `#f59e0b` on navy `#0f172a`.
The name is set in Plus Jakarta Sans ExtraBold, converted to shapes so it looks identical everywhere.

| File | Use it for |
|---|---|
| `spannr-logo.svg` / `spannr-logo-2000.png` | Main logo (icon + name) on light backgrounds: website, invoices, documents |
| `spannr-logo-white.svg` / `spannr-logo-white-2000.png` | Main logo on dark backgrounds |
| `spannr-logo-plain.svg` / `-white.svg` / `spannr-logo-plain-2000.png` | Symbol + name without the square: signage, shirts, vehicle decals |
| `spannr-icon.svg` / `spannr-icon-512.png` / `-1024.png` | App icon, social media profile picture |
| `spannr-icon-maskable*.{svg,png}` | Android home-screen icon (full-bleed square) |
| `spannr-symbol-amber.svg` / `-navy.svg` / `-white.svg` / `spannr-symbol-amber-1024.png` | Symbol on its own, transparent background |
| `apple-touch-icon-180.png`, `favicon-32.png`, `spannr-icon-192.png` | iPhone home screen and browser tab icons |

SVG files scale to any size without losing quality – give these to printers and sign makers.

Colours: Navy `#0f172a` · Amber `#f59e0b` · White `#ffffff`
